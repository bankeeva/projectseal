# Демонстрационные проекты

* `clean_project` — чистый проект без рисков.
* `leaky_project` — синтетические секреты и мусор для проверки всех трёх функций.
  В git-репозитории этой папки нет; она создаётся командой:

  ```bash
  python tools/make_demo.py
  ```

Все ключи и пароли вымышлены. Не используйте эти значения как настоящие.
